# 取件码助手 (小米手机 + 红米 Watch 6 跨端版)

快递短信到达 → 手机自动提取取件码 → 蓝牙直连同步至红米 Watch 6 → 快递柜前抬腕看码并一键标记「已取」。

## 核心特性

- **原生蓝牙双向互通**：基于小米 Vela `@system.interconnect` 与小米穿戴官方 SDK (`xms-wearable-lib_1.4`)，无需开启热点、无需本地 HTTP 端口。
- **手表离线缓存**：基于 `@system.storage` 本地持久化，下楼取件不带手机也能秒开查看取件码；离线标记「已取」后连上手机自动补发同步。
- **全自动捕获短信**：`SmsReceiver` 实时监听新短信 + `WorkManager` 每日 7:00 / 13:00 / 18:00 定时兜底扫描。
- **高准确率本地解析**：移植自 `pain505/1`，支持菜鸟驿站、丰巢、兔喜、妈妈驿站、顺丰、京东、中通、圆通、申通、韵达、极兔、德邦、邮政等主流格式，自动过滤验证码与营销短信。
